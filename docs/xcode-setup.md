# Xcode Setup

## 1. Create a new iOS project

Open Xcode and create a new iOS App project.

Recommended settings:

- Product Name: KizukiNote
- Interface: SwiftUI
- Language: Swift
- Minimum iOS: iOS 17 or later
- Storage: SwiftData

## 2. Add source files

Copy the files under `Sources/KizukiNote` into the Xcode project.

Recommended Xcode groups:

- App
- Models
- Views
- Security

## 3. Build target

Use an iPhone simulator first.

Recommended first test:

- Launch app
- Input a note
- Save note
- Open note list
- Search note
- Edit note

## 4. Product goal

The MVP is complete when a user can capture an idea within 3 seconds.
